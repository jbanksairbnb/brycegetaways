# Photos — drop-in guide

The homepage references the filenames below in `assets/img/`. Until a real
photo exists, each slot shows a soft placeholder tile (no broken images), so
the site looks intact before the photography arrives. Drop a file with the
exact name here and it appears automatically — no code changes needed.

Recommended: JPG, ~2400px on the long edge, saved at ~80% quality.
