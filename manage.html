How to set this up (one time)
  1. On GitHub, go to Settings → Developer settings → Fine-grained personal access tokens → Generate new token.
  2. Give it access to only the jbanksairbnb/brycegetaways repository, with Repository permissions → Contents → Read and write.
  3. Copy the token and paste it in the box above. It's stored only in this browser (localStorage) — never uploaded anywhere but GitHub.
  4. Branch: use main to change the live site. (To preview on the working branch first, enter that branch name instead.)
  5. Click Load, edit, then Save to site. Changes go live in about a minute.

Bookmark this page and keep the link private — anyone with the token can edit the site.
